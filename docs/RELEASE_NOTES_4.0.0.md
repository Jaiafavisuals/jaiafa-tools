# Jaiafa Tools 4.0.0

Jaiafa Tools 4.0.0 focuses on the recurring production work around a design: collecting clear feedback, catching technical problems, preparing variations, and delivering organized assets.

## What's new

- Structured client approval with numbered comments, resolution tracking, decision status, and a feedback-summary board.
- Reviewable QA Auto-Fix and a broader print-production preflight.
- Smart handoff packages with multi-format export, naming tokens, linked assets, document copy, font inventory, and delivery report.
- Reusable artboard templates and CSV-driven text/image generation for up to 250 variations.
- Reference-guided DesignPilot analysis with validated image payloads and safe, editable Illustrator operations.

The release also includes the live AI overlay preview, editable operation values, direction thumbnails, Design QA, Brand Kits, Campaign Resize, and persistent named checkpoints introduced across the 3.4–3.7 roadmap.

## Install

Download `JaiafaTools-v4.0.0.zip`, extract it, and run the included macOS or Windows installer. Restart Illustrator, then open **Window > Extensions (Legacy) > Jaiafa Tools**.

See the repository's installation guide for manual setup and troubleshooting.

## Important

- Adobe Illustrator 2020 or newer is required.
- DesignPilot is optional and requires the user's own OpenRouter API key.
- Review AI operations, batch output, QA results, and handoff files before using them in production.
- This is an unsigned CEP extension; the included installers enable the common CEP debug-mode entries.
