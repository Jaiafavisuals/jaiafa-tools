# Formlane 4.2.0

Design. Review. Deliver.

Jaiafa Tools is now **Formlane**. The panel has a new brand mark and a consistent original SVG icon set across tool navigation, mockup presets, and primary actions. Icons are decorative, preserve button labels, and adapt to active, disabled, and loading states.

Existing extension IDs, the `JaiafaTools` installation folder, saved settings, and document data are retained for compatibility. After updating, restart Illustrator and open **Window > Extensions (Legacy) > Formlane**.
