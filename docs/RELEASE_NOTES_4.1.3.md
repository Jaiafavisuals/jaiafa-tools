# Jaiafa Tools 4.1.3

This build clarifies when a handoff includes a font list only and when it contains font files.

- The option is labeled **Copy local font files — I have permission to share them**.
- The build status warns when fonts were detected but font sharing was not enabled.
- The per-size `Fonts Report.txt` says plainly that font files were not copied and lists the fonts used.
- Font files remain opt-in because the package recipient must be allowed to receive them under the font license.
